# Security policy

Please do not report suspected security vulnerabilities in public issues,
forums or chat. Send a private report to
[security@panomity.com](mailto:security@panomity.com). Include the affected
Quizgeist and Moodle versions, reproduction steps, impact and relevant logs or
proof of concept. Remove personal data, credentials and other secrets before
sending.

Target: acknowledgement within 5 working days. No remediation or disclosure
timeline is promised.

## Supported versions

Quizgeist 1.2.x, including the current release candidate, is supported.
Quizgeist 1.1.x and earlier versions are not supported for security fixes.
